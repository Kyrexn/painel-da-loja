# Painel da loja

Interface web para importação de Programadas e consulta de promoções por término.

O GitHub Pages serve a interface estática. Contas, autenticação e ofertas ficam no serviço HTTPS configurado em index.html. A importação de PDF é processada no navegador, com confirmação antes de salvar.

O APK Android abre a mesma interface. O código Android e do serviço estão em src/.

PDFs reais e contas da loja não fazem parte deste repositório.
